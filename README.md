# MCD2 图鉴 + BD 配装器

《我的世界：地下城 II》图鉴与配装工具（纯前端、零依赖，**双击 html 即可离线使用**）。

| 入口 | 内容 |
|---|---|
| `图鉴.html` | 📖 装备图鉴：装备 / 词条 / 附魔 / 掉落概率 / 世界地图 / 任务 |
| `builder/index.html` | 🎒 BD 配装器 |

**在线访问**
- GitHub Pages：**<https://mcd2.sfish.net/>**（备用 <https://saltedfishjun.github.io/mcd2/>）
- 内网（NAS）：图鉴 <http://192.168.1.8:8095/> ・ 配装器 <http://192.168.1.8:8095/bd/>

## BD 配装器功能

- **9 部位**：近战 / 远程 / 头盔 / 胸甲 / 护腿 / 靴 / 法器 ×3；每件装备 3 词条（独特装备 = 1 固定独特 + 2 可选）+ 1 附魔
- **推荐引擎**：主武器 4 档（近战 / 远程·近身 / 远程·远距 / 法器）× 推荐方向（输出/生存/综合）× 推荐口径（通用/属性）
  - 计分 = 独特固定词条×3 + 可出词条池中该方向最强 N 条（独特 N=2、其它 N=3），再乘装备元素契合系数
  - 权重细则：暴击 / 基础伤害 1.0；攻击速度 0.6；**对次要目标 0.6**；**同伴·召唤物 0.6**；**（近战·远程）武器的暴击伤害 1.25**；与主武器不符的类别 ×0.2
- **词条 / 附魔编辑**：点击词条行就地展开（毛玻璃浮层、自动上翻、不与下方卡片冲突）；词条只取最高阶
- **灵魂系统**：容量自动计算（基础容量 + 配装内「灵魂容量」类加成）+ 开局嗑药回蓝统计
  - **开局能否使用全部法器 = 双条件**：①嗑药回蓝 ≥ 法器总消耗 ②灵魂容量 ≥ 法器总消耗；任一不达标即判「不行」并列出原因
- **综合数据**：大类 → 小类两级统计（如 暴击 → 暴击几率 / 暴击伤害；冷却缩减 → 翻滚 / 法器 / 弹药 / 药水冷却），明细显示**游戏内效果原文**，点击小类可展开来源
- **导出**：导出 JSON（含两级统计）；**导出分享图 PNG**（逐行列出每件装备所选的词条与附魔）
- **分享**：① 分享链接（`…/#bd=<代码>`，对方点开自动载入）② 分享代码手动载入 ③ 本地存档（按码记录名称/时间）
- **多套配装**：本地保存 / 另存 / 载入 / 删除

### 分享方式与环境的关系

| 环境 | 分享方式 | 说明 |
|---|---|---|
| **线上（GitHub Pages）** | **6 位短码** / 分享链接 / 自包含长码 | 短码由项目自建的分享服务提供 |
| **内网 NAS** | 同上 | 与线上共用同一个分享服务、同一份数据 |
| 本地双击（file://） | 分享链接 / 自包含长码 | 服务不可达时自动退回长码 |

> · 线上与内网用的是**同一个分享服务**，所以**短码两边互通**（一边生成，另一边可直接载入）
> · 自包含长码在两站**完全一致**，任何时候都可作为兜底
> · 6 位码字母表去掉易混字符（无 0/O/1/I）；代码格式 = `M2` + 载荷 + 校验位
> · 分享服务地址不在此文档中公开；需要自建/替换时在 `index.html` 里设置 `window.MCD2_SHARE_API`

## 本地使用

1. 克隆/下载本仓库
2. 双击 `index.html`（落地页）→ 进图鉴或配装器；也可直接双击 `builder/index.html`
3. 导出分享图需经 HTTP 打开（浏览器 canvas 跨域保护）：
   ```bash
   python3 -m http.server 8000   # 然后访问 http://localhost:8000/
   ```

## 数据

- `builder/data.js` / `builder/data.json`：272 件装备、61 条装备词条、32 个附魔；`builder/icons/`：505 个图标
- 已与 minecraft.wiki 交叉校对：护手 13 词条 × I/II/III 全对；护甲可用词条池 142/142 一致；护甲独特效果 29/29 一致
  - 唯一差异：震荡波(Shockwave) 击退 本地 125/150/175% vs wiki 25/50/75%（倾向 wiki 笔误）
- **不展示"最终伤害倍率"**：伤害结算管线不在本地档案中；页面百分比为所选词条/附魔文字的**线性相加**，仅供横向对比
