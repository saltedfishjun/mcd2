## 二、伤害机制要点（从游戏参数还原）

**1. 伤害类型**：物理/近战、冰霜、闪电、火焰、毒素、灵魂。武器可带"主类型 + 附加类型"。

**2. 负面状态是最强增伤来源**

| 状态 | 参数效果 |
|---|---|
| **导电 Conductive** | 目标 `BaseDamageResistanceMultiplier ×1.25` → **受到伤害 +25%**；移速 ×1.2 |
| **冻结 Freezing** | 目标移速 ×0.7、近战攻速 ×0.4、远程攻速 ×0.4 |
| 虚弱 Weakness | 目标伤害 ×0.5，且**受到伤害 ×1.5** |
| 强力 Strength | 自身 `BaseDamageMultiplier +1` → **伤害 +100%** |

**3. 结算链**：
`基础伤害 × 自身伤害倍率（强力 +100% / 虚弱 −50%）× 目标受伤倍率（导电 ×1.25 / 虚弱 ×1.5）× 暴击倍率 ± 固定加成`

**4. 暴击**：暴击率与暴击伤害分开堆；战鼓使**暴击伤害翻倍**。

**5. 词条 vs 附魔**：词条槽数由稀有度决定（普通 0 / 稀有 1 / 卓越 2 / 独特 1，另加额外奖励槽）；附魔固定 3 个。**词条阶级受威胁等级限制**（II 阶≥威胁3、III 阶≥威胁6）。

**6. 原型 Archetype**：Fighter / Ranger / Tank / Trickster / Mage / Support / Summoner / Utility + 元素系元素池决定词条可选范围。

## 三、配装方案

思路：护手自带 ①双元素 ②每击"导电+冻结" ③跳跃攻击霜电冲击波 → 资源全砸 **元素增伤 / 对负面状态敌增伤 / 暴击 / 攻速**。

### 近战 · 首席附魔师护手
- **词条（实际可选池）**：锋利、决斗者、先锋、赏金猎人、强力、精准、暴击、暴击锋刃、灵巧、不屈、击退、搜刮者、袭击者
  - 优先级：**锋利 ≈ 决斗者 > 强力 / 精准 > 先锋 / 赏金猎人**
- **附魔（3）**：
  1. **闪电涌动 Lightning Surge**：冲击波造成 **60% 武器伤害** + 施加"变弱"（=虚弱，目标受伤 ×1.5）
  2. **引雷 Thundering**：25% 几率把 15% 武器伤害转为闪电
  3. **旋风攻击 Swirling**：额外 **50% 武器伤害**近身 AoE
  - 备选：寒霜斩（冻结延长）、坠落冲击（跳跃系）、末影地雷

### 护甲（4 件，可混搭）
| 部位 | 推荐 | 固定效果 |
|---|---|---|
| 头盔 | **神谕王冠** | 闪电法师：闪电伤害 **+25%** |
| 胸甲 | **神谕披风** | 污染：负面状态**时长 +100%** |
| 护腿 | **寒霜长衬裤**（群怪）/ **无畏胫甲**（首领） | 斗士：次要目标 +50% / 先锋：满血敌人 +60% |
| 靴子 | **君主利爪** | **恶霸：对受负面状态影响的敌人 +50%** ← 与护手绝配 |

- 护甲**词条**优先：闪电法师 / 冰霜法师（元素增伤）· 污染（状态时长）· 迅捷（攻速）· 强力 / 暴击
- 护甲**附魔**：力量增幅器（用法器后下次攻击 +20%）· 活力（翻滚后下次攻击 +20%）· 空翻（多一次翻滚）

### 远程
**幻翼弓★（跳跃射击）** 或 **典范弓★（冲击：远程伤害 +30%）**；配 **导电箭袋 / 冰冻箭袋** 远程补状态。

### 循环
战鼓 → 战斗真菌 → 冲进怪群普攻（每击自动上导电+冻结，君主利爪 +50% 全程生效）→ 爆发用跳跃攻击触发霜电冲击波 → 翻滚接"活力"补刀。
