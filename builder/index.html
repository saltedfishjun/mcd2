MCD2 配装器 Demo

数据取自本地图鉴档案（272 件可装备 · 61 装备词条 · 32 附魔）· 全前端 · 进度与配装存本地
规则：一套 = 近战×1 + 远程×1 + 头盔/胸甲/护腿/靴 + 法器×3。每件装备 3 个词条（独特 = 1 独特词条固定 + 2 可选；其他 = 3 可选）； 每件 1 个附魔，可选范围按图鉴附魔池（法器无附魔）。
使用提示
· 点格子选装备；已装备的格子点开可改词条/附魔，右上角 ✕ 卸下
· 同一件装备不能重复选同一个词条
· 推荐 = 「主武器」（近战 / 远程·近身 / 远程·远距 / 法器）×「推荐方向」×「推荐口径」
· 远程主用时区分距离：「贴身/近距离」与「远距/狙击/蓄力」会按所选取向决定权重（不匹配的降权）
· 通用：伤害按数值同权比较，元素仅 ×1.05 微调；属性：选中元素的词条权重提高（×1.8）
· 「导出分享图」生成 PNG，可直接发群
